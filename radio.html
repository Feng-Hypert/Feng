数据备份 & 网站部署指南

个人数据 歌单与歌词校准备份 / 恢复

一键导出自建歌单、歌曲信息修改与歌词时间轴偏移为 JSON 文件，换设备或清理缓存后可随时恢复。

步骤 1 添加到 iPhone 主屏幕（Safari 网页 App）

1. 使用 iPhone 自带的 Safari 浏览器打开你的网站地址。
2. 点击底部工具栏的 分享按钮（方框向上箭头）。
3. 向下滑动并点击 「添加到主屏幕」，即可获得全屏无地址栏的「FENG MUSIC」桌面 App。

步骤 2 托管到静态网站（GitHub Pages / Cloudflare Pages）

将本文件保存为 index.html 上传到网站根目录。同目录新建 songs.json 即可自动加载服务器上的 MP3 歌曲与预设歌单： 

{
  "songs": [
    {
      "id": "night-voyager",
      "title": "夜航星",
      "artist": "不才",
      "album": "三体同人曲",
      "url": "./music/night-voyager.mp3",
      "cover": "./music/night-voyager.jpg",
      "lrc": "./music/night-voyager.lrc",
      "bitrate": "WEB · STEREO"
    }
  ],
  "playlists": [
    {
      "name": "深夜单曲循环",
      "trackIds": ["night-voyager"]
    }
  ]
}
